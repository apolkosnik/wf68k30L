CURRENT SCALAR CHARACTERISTICS:
✓ Single instruction issue per cycle (1-issue)
✓ Sequential decode from FIFO
✓ One ALU shared by all instructions
✓ One register write port per destination type
✓ One memory port (read OR write, not both)
✓ Register-in-use flags for hazard detection (ADR_IN_USE, DR_IN_USE)
✓ Optional NO_PIPELINE mode (fully scalar, no overlap)

================================================================================
                SUPERSCALAR CONVERSION REQUIREMENTS
================================================================================

MAJOR CHANGES NEEDED:

1. FETCH STAGE (HIGH EFFORT: 1,332 → 2,664-3,996 lines)
   ✗ Single decoder → Parallel decoders (2-4)
   ✗ Single IPIPE → Multiple independent IPIPEs
   ✗ 1 instr/cycle → 2-4 instr/cycle fetch bandwidth
   + Alignment logic for variable-length instructions
   + Inter-decoder synchronization

2. DECODE STAGE (HIGH EFFORT: 2,533 → 5,000-8,000 lines)
   ✗ Single state machine → Multiple parallel controllers
   ✗ Register-in-use flags → Register rename tables + scoreboards
   ✗ Sequential issue → Dynamic issue logic
   + Reservation stations for operand buffering
   + Dependency matrices for N instructions
   + Issue queue and priority encoders

3. EXECUTION STAGE (MEDIUM EFFORT: 1,264 → 2,000-3,000 lines)
   ✗ Single ALU → Multiple ALUs (2-4)
   + Result forwarding network (bypass logic)
   + Out-of-order execution scheduling
   + Specialized units (multiplier, divider, shifter)

4. MEMORY SUBSYSTEM (MEDIUM EFFORT: 875 → 1,500-2,500 lines)
   ✗ Single read/write port → Multiple independent ports
   + Load/store queue for memory ordering
   + Cache integration (I-cache + D-cache mandatory)
   + Cache coherency protocols

5. REGISTER FILES (HIGH EFFORT: 815 → 2,000-3,000 lines)
   ✗ 8 AR + 8 DR (16 total) → 32-64 physical registers
   + Register rename logic and rename tables
   + Multi-port register file (4+ read ports, 2+ write ports)
   + Scoreboard for tracking register readiness

6. WRITEBACK & RETIREMENT (HIGH EFFORT: New component)
   + Reorder buffer (ROB) - 16-32 entry buffer
   + In-order retirement logic
   + Exception handling redesign for speculation
   + Misprediction recovery logic

- Arithmetic: ADD, SUB, MULS, MULU, DIVS, DIVU, ABCD, SBCD, NBCD
- Logical: AND, OR, EOR, NOT
- Shift/Rotate: ASL, ASR, LSL, LSR, ROL, ROR, ROXL, ROXR

- Bit Test: BCHG, BCLR, BSET, BTST, CAS, CAS2, TAS, CHK, CHK2, CMP2

- Special: LEA, PEA, LINK, UNLK, EXG, SWAP, CLR, NEG, NEGX, NOT, TST, EXT, EXTB, MOVEC, MOVE_USP
